Use it now

Naima lives in a git repository: the folder that keeps your project and all its history. You don’t need to know git: your AI agent creates the repository if there is none yet, and installs Naima in it.

Ask your agent

Open your AI agent in your project’s folder, or in a new empty one, and give it this:

Please install https://github.com/vincenzoml/naima in the root of this repository; create a repository at the root if missing.

For advanced users

Run this in the root of your git repository:

curl -fsSL https://vincenzoml.github.io/naima/install.sh | sh
irm https://vincenzoml.github.io/naima/install.ps1 | iex

Then your agent runs deno run -A naima-tracker/naima/naima.ts check and works by Naima from the next session on.
