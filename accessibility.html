Accessibility of this site

We want everyone to be able to read this site and use it, with a keyboard, a screen reader, a phone or a larger text size. This page says how far we have got.

The standard we aim at

The site aims at the Web Content Accessibility Guidelines (WCAG) 2.2, level AA. These guidelines cover the web criteria of the European standard EN 301 549, which the European Accessibility Act and the Web Accessibility Directive refer to.

Where we stand

As of the audit of 2026-11-09, the site fully conforms to WCAG 2.2 level AA. The audit covered these five pages:

  • the home page
  • the documentation page
  • the install page
  • the “Naima in one minute” page
  • the “Naima checks itself” page

This statement page was checked the same way.

How it was checked

On 2026-11-09 each page was checked three ways, on a desktop screen (1280 pixels wide) and on a phone screen (375 pixels wide):

  • the automated accessibility checks of Naima’s user-interface stance, which test colour contrast, keyboard focus, the size of touch targets, reflow at narrow widths, larger text and reduced motion;
  • axe, an open-source accessibility testing engine, with the WCAG 2.2 rules;
  • a manual review of keyboard order and the focus ring, the skip link, headings and landmarks, text alternatives for images and the metro-map figure, link names, the page language and zoom to 200%.

Known limitations

  • The documentation page shows text that it fetches from the Naima repository on GitHub when it opens. The page around the text is checked; the text itself comes from the product’s documentation and is written in plain markdown, which is rendered as headings, lists, tables and code.
  • Pages on GitHub that this site links to are not part of this site and are outside this statement.

Tell us about a problem

If something on this site is hard or impossible to use, please report it as an issue on the Naima repository, with the label “accessibility”. Open a new accessibility issue: the form already has the label and a few questions to answer. We read these reports and answer them on the issue.

When this statement was prepared

This statement was prepared on 2026-11-09. It is reviewed at each release of Naima.
