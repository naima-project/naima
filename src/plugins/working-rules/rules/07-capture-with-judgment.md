A request, a report, a decision or a deferral the owner has settled is filed at once, in the agent's own words, never the chat verbatim: duplicates searched
first and linked instead of refiled, triaged on the spot, and marked with who asked: `--asked-by owner` only for what the owner said, the default `agent` for
what the agent found itself. While the owner is thinking aloud or asking in principle, discuss and file nothing; once that exchange has settled, ask once
whether to file it. Never file or start work in the middle of the owner's thought. "I already told you" means a report was lost: file it now and say it was
missing.

## Why

a request said once and never filed has to be said again; an item filed for a passing thought is noise to review and undo, and filing mid-conversation
interrupts the owner's thinking.
