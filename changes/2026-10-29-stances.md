---
title: Naima knows stances, and adopts one by name
kind: feature
affects:
  - api
  - usage
commands:
  - added stances
  - added stance
---

A stance is a plugin whose manifest says `kind: "stance"`: a set of authored choices and rules a project adopts as a whole. A stance may also list `examples`,
paths inside its repository. `naima stances` lists the stances published in the naima-project organisation on GitHub, the repositories named
`naima-stance-<name>`, and says so when it cannot reach GitHub. `naima stance adopt <name>` pins the stance by commit in `naima.json` as `plugins.stance-<name>`
and runs its own adoption when it has one. `naima stance status` says whether a newer commit exists, and `naima stance examples <name>` lists the examples. A
plugin pinned from git at the tip of its branch is now checked out on its first fetch, instead of being left empty and refused.
