---
title: Plugins declare the tools they need, and naima tools installs them
kind: feature
affects:
  - api
  - usage
commands:
  - added tools
---

A plugin can say which outside tools it needs, such as mCRL2 or Storm. `naima tools` reports which ones are present, shows where they are, and installs a
missing one into Naima's own folder after asking, or removes it.
