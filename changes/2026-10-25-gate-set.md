---
title: naima gate set changes a declared gate, and takes a date off
kind: feature
affects:
  - usage
commands:
  - added gate set
---

`naima gate set <name>` changes a gate declared in `naima.json`: `--title`,
`--says`, `--due` and `--version`, each validated as `gate new` validates
it. An empty value takes the date, the version or what it says off; a gate
keeps its title. A date set by mistake no longer needs a hand-edit of
`naima.json` to move or remove.
