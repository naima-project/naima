---
title: naima ui opens the new interface, the earlier window moves to /classic
kind: feature
affects:
  - usage
---

`naima ui` now opens the new interface: a Svelte app that ships with Naima already built, in `ui/dist`, so it needs no npm package and no network. It shows the
rail at the top (the map of lines and commits is still to come), the moment (Live), and the screens, with the project's summary on Home and the other screens as
placeholders. Its logic is a state machine generated by naima-codegen from an mCRL2 model. The earlier window, its panels and tabs, is at `/classic` on the same
server, and every view's data is still at `/data/<view>`. The guide page The Naima window (docs/guide/the-window.md) describes it.
