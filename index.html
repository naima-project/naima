For AI agents

Naima is born for software: a silent software house of AI agents that applies industry-grade practice (tests, metrics, reviews, gates) and formal methods for an owner who need not know them, and runs any other project with that work’s own checks. If you were asked to install Naima in a repository, the whole procedure is the README of https://github.com/vincenzoml/naima, section Install (raw: https://raw.githubusercontent.com/vincenzoml/naima/main/README.md; also llms.txt); read it and follow it. In short: if git is not installed, install it (macOS: xcode-select --install or Homebrew; Linux: the package manager; Windows: winget install Git.Git); then, in the root of this repository (if it is not a git repository yet, create one at the root with git init), run the installer one-liner for this system (below), run deno run -A naima-tracker/naima/naima.ts check until it passes, read naima-tracker/naima/skills/naima/SKILL.md and work by it, and add this line, verbatim, to the repository’s agent instruction file (AGENTS.md, CLAUDE.md, or the one you read; if none, create AGENTS.md):

This repository tracks its work with Naima: at the start of every session read naima-tracker/naima/skills/naima/SKILL.md and `naima rules --audience agents`, and work by them.

State-of-the-art project management and
software engineering, seamless, automatic, transparent.

  • 🙂 You don’t need to know git, code or project management. Naima and your LLM agent become your software house in-a-box.
  • 🤖 You talk to your AI agent as usual. Naima gives it a method: every request becomes an item, every item a plan, every plan a change that is tested before it lands.
  • 🧪 Nothing is “done” until it’s proven. A fix counts only when a test has seen it fail and then pass. Where it matters, a model checker proves it.
  • 👥 Many agents, no chaos. Each one works in its own space and hands back finished work.
  • 🗂️ It all lives in your repo. Plain files, versioned with your code. No server, no account.
