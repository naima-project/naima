# Naima in one minute

When you build something by asking an AI, the first version usually comes
quickly. The trouble starts later. A fix breaks something that used to work,
the AI says "fixed" when it isn't, and the next session has forgotten what the
last one decided.

Naima is a way of working that you add to your project, so the AI you already
use works like a careful software team. You keep talking to your agent as
usual. Behind the scenes, every request becomes a written item, every change
is checked by a test before it counts as done, and every decision you make is
kept, so you are never asked the same question twice. Different agents build
and check the work, so nobody judges their own. When there is something only
you can decide, you are asked, one question at a time.

Everything lives in a folder of your project, as plain files kept in git. There
is no account, no server and no subscription, and you can change agent or model
whenever you like. Naima is free and open source.

It was born for software, and it works for other long-lived work too, such as
a data analysis or a paper written with colleagues.

To start, open an agent that can run commands in your project's folder and ask
it to install Naima ([how](install.md)).
