A request, a report, a decision or a deferral the owner has settled is filed in the same turn, once the owner has been answered and never before the answer, in
the background where it can (a worker, or right after the reply), in the agent's own words, never the chat verbatim: duplicates searched first and linked
instead of refiled, triaged on the spot, and marked with who asked: `--asked-by owner` only for what the owner said, the default `agent` for what the agent
found itself. While the owner is thinking aloud or asking in principle, discuss and file nothing; once that exchange has settled, ask once whether to file it.
Never file or start work in the middle of the owner's thought. "I already told you" means a report was lost: answer, then file it and say it was missing.

## Why

a request said once and never filed has to be said again; an item filed for a passing thought is noise to review and undo, filing mid-conversation interrupts
the owner's thinking, and filing before answering keeps the owner waiting for bookkeeping.
