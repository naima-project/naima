Use it now

NAIMA lives in a git repository: the folder that keeps your project and all its history. You don’t need to know git: your AI agent creates the repository if there is none yet, and installs NAIMA in it.

Ask your agent

You need an AI agent that can run commands in a folder, such as the Code tab of the Claude desktop app, Claude Code, Codex or Cursor. Open it in your project’s folder, or in a new empty one, and give it this:

Please install https://github.com/naima-project/naima in the root of this repository; create a repository at the root if missing.

For advanced users

Run this in the root of your git repository:

curl -fsSL https://naima-project.github.io/naima/install.sh | sh
irm https://naima-project.github.io/naima/install.ps1 | iex

Then your agent runs deno run -A naima-tracker/naima/naima.ts check and works by NAIMA from the next session on. NAIMA writes only in its own folder, naima-tracker/, and one line in your agent’s instruction file, so everything it does is in git and can be undone.
