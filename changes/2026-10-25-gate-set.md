---
title: naima gate set changes a declared gate, and takes a date off
kind: feature
affects:
  - usage
commands:
  - added gate set
---

`naima gate set <name>` changes a gate declared in `naima.json`: `--title`,
`--says`, `--due`, `--version`, `--holds-on` and `--coverage`, each validated
as `gate new` validates it, and `--full-suite` or `--no-full-suite` makes it a
release gate that waits for the full suite, or no longer. An empty value takes the date, the version or what it says off; a gate
keeps its title. A date set by mistake no longer needs a hand-edit of
`naima.json` to move or remove.
